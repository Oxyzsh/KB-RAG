# internal/ingest/chunker

把 `loader.Document` 切成带标题路径的检索片段。每个 `Chunk` 会单独嵌入、写入一条 `chunks` 记录，并单独参与 top-k 检索。

## 入口

```go
type Chunk struct {
    Seq     int
    Heading string // 例如 "人事制度 > 休假 > 年假"
    Text    string
}

func Split(doc loader.Document, size, overlap int) []Chunk
```

参数来自配置：默认 `size=500`、`overlap=80`，必须满足 `size > overlap > 0`，否则返回空。

`size` 按 **Unicode 字符（rune）** 计数，不是字节数，也不是 token 数。

## 处理流程

```text
Document{Blocks}
  → 按标题维护标题栈和当前段落缓冲区
  → 普通正文打包 / 超长段落按句末标点拆分
  → Markdown 表格独立处理
  → 输出 []Chunk{Seq, Heading, Text}
```

- `Block.Level == 0`：正文段落；
- `Block.Level == 1..6`：标题；
- `Heading` 由标题栈用 ` > ` 连接；
- `Seq` 在单文档内从 0 递增。

## 规则

### 1. 按标题边界切分

遇到标题时先冲刷当前缓冲区，保证片段不跨标题；然后按标题层级更新标题栈。

### 2. 标题路径

维护标题栈；新标题的层级为 `L` 时，弹出所有 `level >= L` 的旧标题，再压入新标题。无标题文档的 `Heading` 为空。

PDF 没有真实标题：Loader 会把每页插入为 `第 N 页` 的一级标题，因此页边界也会触发切分。

### 3. 普通段落打包

同一标题下，正文段落依次加入缓冲区，段落间用换行连接。加入下一段会超过 `size` 时，先输出当前缓冲区。

普通段落打包**不使用重叠**。

### 4. 超长段落

单个段落超过 `size` 时：

- 以 `size` 为窗口；
- 从窗口后半段向前寻找 `。`、`！`、`？`、`；` 或换行作为切点；
- 找不到就在窗口末尾切；
- 下一片起点回退 `overlap` 个字符，形成重叠；
- 每片少于 10 个字符时丢弃。

重叠只用于这种超长段落拆分。

### 5. 碎片丢弃

最终片段少于 **10 个字符**时丢弃，用来过滤空行、孤立标点和过短碎片。第一期没有专门识别“导航文本”，只依赖这个长度阈值。

### 6. 表格

识别条件：Markdown 表格块从表头行开始，第二行是分隔行（只包含 `|`、`-`、`:` 和空格），后面至少有一行数据。

- 表格作为独立片段，不与前后段落合并；
- 表格总长度超过 `size` 时按行拆分；
- 每个片段都重复表头与分隔行；
- 单行即使超过 `size` 也不拆开，保证一行数据完整；
- 表格片段不使用字符重叠，靠重复表头保留上下文。

整块必须都是表格；如果表格和普通文字混在同一个 Block 中，会回退到普通段落逻辑。

### 7. 序号

`Seq` 按输出顺序从 0 递增，用于文档内排序和相邻片段定位。

## 示例

```markdown
# 人事制度

## 休假

年假规定……

## 食堂

食堂开放时间……
```

输出两个片段，Heading 分别为：

```text
人事制度 > 休假
人事制度 > 食堂
```

如果“年假规定”超过 500 字符，会按句末标点拆成多个片段，相邻片段重叠约 80 字符。

表格示例：

```markdown
| # | 动作 | 说明 |
|---|---|---|
| 1 | 发消息总线 | topic=alarm |
| 2 | 推园区平台 | yqpt.SendAlarm |
| 3 | 记活动状态 | activeTracker |
```

表格会独立成片；如果超过 `size` 被按行拆开，每个片段都会以表头和分隔行开头。

## 限制与注意

- `size` 是字符数，不是 token；需要按模型上下文精确控制时，应额外做 token 估算。
- 表格识别只覆盖 Markdown 表格；DOCX 表格由 Loader 拼成普通文本（单元格用 ` | `、行之间换行），不会进入表格分支。
- 单行表格过长时，片段会超过 `size`，这是为了保证行结构完整。
- 标题边界是硬规则，标题下内容很少时会形成较小片段。
- 修改 `chunk.size` 或切分算法后，已有库不会自动重建：`ingest` 的 SHA-256 跳过只比较文件内容，不包含切分版本。需要删除库或换新库重新 ingest。

## 测试

[chunker_test.go](chunker_test.go) 覆盖：

- 标题边界与嵌套标题路径；
- 段落打包；
- 100 字符上限与 20 字符重叠；
- 碎片丢弃与非法参数；
- 表格保持完整；
- 超大表格按行拆分且每片重复表头；
- 表格与前后段落分离。
