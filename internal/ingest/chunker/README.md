# internal/ingest/chunker

把 `loader.Document` 切成带标题路径的片段。

## 入口

```go
type Chunk struct {
    Seq     int
    Heading string // 例如 "人事制度 > 休假 > 年假"
    Text    string
}

func Split(doc loader.Document, size, overlap int) []Chunk
```

参数来自配置：默认 `size=500`、`overlap=80`，必须满足 `size > overlap > 0`，否则返回空。

## 规则

1. **按标题边界切分**：遇到标题先冲刷当前缓冲区；新片段不跨标题。
2. **标题路径**：维护标题栈；层级回退时弹出更深层标题。无标题文档的 `Heading` 为空；PDF 的页码标题形成 `第 N 页`。
3. **段落打包**：同一标题下按段落积累，加入下一段会超过 `size` 时先冲刷。
4. **超长段落**：按中文句末标点 `。！？；` 与换行切分；切点至少落在窗口后半段，避免产生过碎片段；相邻片段重叠 `overlap` 个字符。
5. **碎片丢弃**：最终片段少于 10 个字符时丢弃。
6. **序号**：`Seq` 按输出顺序从 0 递增。

## 表格

Markdown 表格（表头行 + 分隔行 + 至少一行数据）按特殊规则处理：

- 表格作为独立片段，不与前后段落合并；
- 表格总长度超过 `size` 时按行拆分，**每个片段重复表头与分隔行**；
- 单行即使超过 `size` 也不拆开，保证一行数据完整；
- 表格片段不使用段落重叠，靠重复表头保留上下文。

## 示例

```text
# 人事制度
## 休假
年假规定……
## 食堂
食堂开放时间……
```

输出两个片段，Heading 分别为 `人事制度 > 休假`、`人事制度 > 食堂`。
