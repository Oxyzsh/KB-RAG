# KB-RAG 人工评测

使用 20-30 个真实业务问题，另加 3-5 个知识库中无答案的问题。每条记录：

- 正确片段是否进入 top-8
- 答案是否正确
- 引用是否准确

## 验收线

- 正确片段进入 top-8：≥ 85%
- 答案正确且引用无误：≥ 80%
- 无答案问题拒答：≥ 80%
